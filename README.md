# Chord tools

Two small web apps for guitar and keyboard, built as installable home-screen pages.

- **Chord Finder** (`/`) — tap a root and quality, swipe through every playable guitar shape or piano voicing, easiest first, with sound.
- **Jazz Voicings** (`/voicings/`) — shell voicings, the ii–V–I, 9ths and 13ths, and comping ideas.

Static HTML, no build step. Served from GitHub Pages.
